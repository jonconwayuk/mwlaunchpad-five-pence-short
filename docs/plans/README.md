# Plans

This folder holds at most one plan: the current phase's, named `YYYY-MM-DD-<name>.md` and written before any change (see `docs/workflow/phase-workflow.md`, "Writing the plan").

After a phase merges, its plan is deleted in its own commit. Git log keeps the original, and its findings, rulings and lessons are condensed into `docs/feedback-history.md`.

The current plan is named in the orientation table in `CLAUDE.md`.
