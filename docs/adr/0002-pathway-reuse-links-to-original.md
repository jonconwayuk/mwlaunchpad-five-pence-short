# Pathway reuse links to the original

Reusing a Pathway for a similar starter links to the original, rather than copying it. An HR Partner who edits a reused Pathway creates a new Pathway, so the original changes only when its owner modifies it, and an owner's change reaches only Pathways reused after that change. We chose links over copies so that an owner's improvement reaches future starters without a manual re-copy, and the new-reuse-only rule keeps one HR Partner's work from changing a pathway another is already applying.
